# Корпоративный портал АО «Стройтранснефтегаз»

**Назначение:** консолидация и аналитика данных по заявкам на оплату, реестрам
платежей, договорам, дебиторско-кредиторской задолженности и объектам строительства.

**Пользователи:** сотрудники департамента цифровизации, финансовый блок,
руководители проектов и подразделений.

---

## Что делает портал

Портал собирает данные из пяти источников (Excel-выгрузки из 1С и смежных
систем) и превращает их в единое информационное пространство:

| Источник | Что содержит |
|---|---|
| **Заявки на оплату** | Каждая заявка: сумма, контрагент, договор, статус согласования, период услуги |
| **Реестры платежей** | Реестры с суммами, статусами банка, датами этапов согласования |
| **Договоры** | Портфель договоров с лимитами, сроками, контрагентами, ЦФО |
| **Задолженность (КЗ/ДЗ)** | Кредиторская и дебиторская задолженность с разбивкой по документам |
| **Объекты** | Справочник объектов строительства с координатами, проектами, ответственными |

На основе этих данных формируются:

- **Отчёты** — быстрый отчёт по неоплаченным заявкам и экспорт любых данных в Excel.
- **Дашборды** — аналитика по договорам, финансам, операциям, задолженности,
  средним расходам и портфелю договоров.
- **Мой дашборд** — персональная страница, которую пользователь собирает из виджетов.
- **Карточки договоров** — детальная информация по одному договору с построчной
  сверкой документов расчётов.
- **Конструктор отчётов** — создание собственных табличных и KPI-отчётов.
- **Объекты** — справочник объектов с картой, списком и связью с заявками.

## Карта портала
Главная
├── KPI: КЗ, ДЗ, сумма неоплаченных заявок, активные договоры
├── Требует внимания: истекающие, лимиты, без срока, расхождения, прогноз исчерпания
└── Дата актуальности данных задолженности

Мой дашборд
└── Персональные виджеты (KPI, таблицы, графики)
├── Добавление виджетов из каталога
├── Перетаскивание (drag-and-drop)
├── Изменение размера (small / medium / full)
└── Удаление и сброс к стандартному набору

Отчёты
└── Быстрый отчёт (неоплаченные согласованные заявки)
└── Экспорт: быстрый / все заявки / все реестры

Договоры и расчёты
├── Таблица всех договоров с лимитами, КЗ, ДЗ, расхождениями
├── Фильтры: ответственный, признак оплаты, проблемные галочки
└── Карточка договора — сверка по документам расчётов

Портфель договоров
├── Мёртвые (нет заявок > 6 мес.)
├── Растущие (расходы выросли > 50%)
├── Истекающие (в течение 60 дней)
└── Расхождения КЗ и заявок

Объекты
├── Список объектов с фильтрами по проекту/типу/статусу/городу
├── Карта с кластеризацией и попапами
└── Карточка объекта (информация + миникарта)

Дашборды (доступны через «Все разделы»)
├── Финансы
├── Операции
├── Динамика оплат
├── Средние расходы
└── Конструктор отчётов

Сервис
├── Импорт (заявки, реестры, договоры, задолженность)
├── Справка
└── Настройки (стартовая страница, смена пароля, скрытые разделы)

Администрирование (только для admin)
├── Пользователи
├── Токены объектов
└── Проверка матчей

## Персонализация

### Sidebar

Боковое меню состоит из трёх уровней:

| Уровень | Что | Кто управляет |
|---|---|---|
| **Фиксированные** | Главная, Мой дашборд, Отчёты, Договоры, Портфель, Объекты, Импорт, Справка, Настройки | Администратор |
| **Закреплённые** | Пользователь сам поднял в основной блок | Пользователь |
| **Скрытые** | Разделы, которые пользователь убрал из меню | Пользователь |

**Как работать:**
- В блоке **«Все разделы»** наведите на любой раздел → появятся две иконки:
  - `☆` — закрепить в основном меню;
  - `👁` — скрыть совсем.
- Закреплённые разделы помечены жёлтой звездой `★` — наведите, чтобы открепить.
- Скрытые разделы можно вернуть через **Настройки → Скрытые разделы**.

### Мой дашборд

- **Добавить виджет** — кнопка в шапке страницы, открывает каталог.
- **Перетащить** — за иконку `⋮⋮` слева от названия.
- **Изменить размер** — иконка `⤢` (цикл small → medium → full).
- **Удалить** — иконка `×`.
- **Сбросить** — вернуть стандартный набор виджетов.

### Стартовая страница

В **Настройках** можно выбрать:
- **Главная** — KPI и блок «Требует внимания».
- **Мой дашборд** — персональный набор виджетов.

## Ключевые принципы работы

### Факт vs План

- **Оплаченные заявки** — исполненные обязательства.
- **Неоплаченные заявки** — текущие обязательства перед контрагентом.

### Исключения

Из аналитики исключаются заявки:
- со статусом `Аннулирован`,
- со статусом `Подготовлен` (черновики),
- без заполненного статуса согласования (кроме отдельных отчётов).

### Периоды

Аналитика по расходам строится на поле **«Период услуги»**, которое
извлекается из назначения платежа автоматически.

### Пролонгация

Если в договоре указано одно из условий пролонгации
(`Автоматически на год`, `Автоматически на неопределенный срок`,
`Допускает продление`), предупреждения об истечении срока не показываются.

### Фильтрация по ЦФО

Пользователи не-администраторы видят только данные своего подразделения.
Фильтр применяется автоматически во всех аналитических разделах.

## Быстрый старт (для администратора)

Полная инструкция — в **Руководстве администратора**. Коротко:

1. Настроить `.env` с параметрами БД и `SECRET_KEY`.
2. Запустить контейнеры: `docker compose up -d --build`.
3. Открыть портал, войти под администратором.
4. Загрузить Excel-файлы через раздел «Импорт».
